Products — inline edit (table view)

LPD-9102 — inline editing for the Frontend Data Set, table view. Every field renderer is on the table and they all validate and commit the same way: edit, then ✓ (or Enter) to save and ✕ (or Escape) to cancel. Try an empty name, a bad URL, a quantity of 1000, a past expire date, a date typed by hand, and the locked cells. Switch the server off to see what each field does when a save fails.
